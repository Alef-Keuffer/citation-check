# citation-check

Checks the citations in a pandoc Markdown report against the cited sources themselves. Each citation carries a verbatim passage from its source, and the check proves deterministically that the passage is in the cited chapter, section or page. A model then judges whether the passage carries the claim.

Status: designed, not built yet. The design is in `GLOSSARY.md`, `docs/adr/` and `docs/grilling/`.
